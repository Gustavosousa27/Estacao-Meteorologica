# Firmware do ESP32

Adicione aqui o arquivo `.ino` da estacao meteorologica que foi testado no Arduino IDE.

Antes de publicar, remova as credenciais reais do Wi-Fi e substitua por placeholders (`SEU_SSID`, `SUA_SENHA`).

Confira o IP da API configurado no firmware: ele precisa apontar para o computador onde os containers estao rodando.

Os sensores do projeto incluem DHT22, BMP180, BH1750, MQ-135 e detector de chuva. Documente a pinagem usada no firmware final.
